# BLACKPINK Interactive Media Platform

A responsive, high-performance web application dedicated to showcasing the discography, history, and multimedia assets of the global music group BLACKPINK. This project demonstrates advanced frontend layout architecture, smooth user interactions, and cross-platform media integration.

## 🚀 Key Interactive Features
*   **Dynamic Hover Interactions:** Implemented responsive CSS animations on member profiles. Hovering triggers a fluid transition that overlays contextual biography text and applies interactive visual feedback.
*   **Chronological History Timeline:** Engineered a structural timeline tracking major milestones, album releases, and global achievements utilizing semantic document outlines.
*   **Embedded Audio & Video Streams:** Integrated asynchronous Spotify and YouTube Music iframe players, allowing seamless background playback without disrupting the document layout or user session.

## 🛠️ Technical Stack & Architecture
*   **HTML5:** Structured with semantic markup (`<main>`, `<article>`, `<time>`) to maximize accessibility and clean DOM rendering.
*   **CSS3:** Designed with modern layout properties, explicit component positioning, and hardware-accelerated transitions (`transition`, `transform`) for high-performance interactive states.
*   **Asset Management:** Organized localized stylesheets and asset directories to maintain low latency, fast loading times, and a modular separation of concerns.
